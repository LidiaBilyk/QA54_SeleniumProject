# QA54_SeleniumProject

A training project focused on automated testing for the Telran web application.

Project objective: To learn how to create, execute, and maintain automated UI tests using Python.

Application under test: https://telranedu.web.app/login

Technologies used:

Python — programming language

Selenium WebDriver — browser automation

pytest — testing framework

Google Chrome — browser for test execution

Git / GitHub — version control system
